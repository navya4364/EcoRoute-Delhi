About the Project

EcoRoute Delhi is a waste transport optimization prototype designed to help city planners evaluate routing efficiency, fuel reduction, and carbon offset across dense urban areas like Vasant Kunj and Lajpat Nagar.

Data disclaimer: This is a hackathon prototype. All numbers (distance, fuel, CO₂, cost, tonne-km, waste load, segregation rates), boundaries, routes and hub assignments are synthetic sample data used to demonstrate the concept. Area names are used for illustration only. This project is not affiliated with any government body. Only the OpenStreetMap base map is real. With actual data from the relevant authorities, the same dashboard could produce real results.
